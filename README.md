# Complexity metrics parser for Swift, written on C#.

## Calcilates Gilb metrics for a Swift program.

### Just put your code in the window and press calculation button!

##### Calculates:
- Absolute complexity(CL) - amount of conditional operators;
- Relative complexity(cl) - rate of conditional operators to other operators;
- Max Nesting(CLI);
- Total operatirs - amount of non-conditional operators.

For starting up you nedd .NET, .NET MAUI installed on your machine.
